2.面向对象相关的概念
    对象
        万物皆对象,在自然界中只要是客观存在的事物都是对象
    类
        类是对大量对象的共性的抽象
            有什么     ---------属性
            能做什么   ---------方法
        类是创建对象的模板
        类是客观事物在人脑中的主观反映

3.定义类的语法以及类中的成员
    class Person:
        # 属性 -- 类属性（所有类创建出来的对象共用）
        home = "earth"

        # 方法
        def __init__(self, name, age):
            # 属性 --实例属性（每个类创建出来的对象独有）
            self.name = name
            self.age = age

        def eat(self):
            print("eating")

        def drink(self):
            print("drinking")
    说明
        类是对大量对象共性的抽象，其中主要定义了属性和方法
        class是一个关键字，主要是用来标记定义类
        Person是当前类的类名
        类名后的:必须要加
        缩进后的内容是类体
        属性
            类属性： 所有类创建出来的对象(实例)共用
            实例属性:每个类创建出来的对象独有
        方法
            实例方法
4.类的操作

5.__init__方法
    在定义类的时候，__init__不是必须的
    如果没有显示提供__init__，系统底层会提供一个默认的无参的__init__方法
    在一些资料中，将__init__称之为构造函数，其实这种说法不严谨
    因为构造函数主要的功能是帮助我们创建对象的，在python语言中，真正对象的创建操作是一个叫__new__的方法完成
    只不过__new__创建完对象之后，会将创建好的对象交给__init__，在init方法中，主要完成的功能的是对新创建的
    对象进行一下初始化操作，例如：给对象添加属性(实例属性)以及给属性赋值

    如果显示的提供了__init__方法，在创建对象的时候，传递的参数个数，必须和__init__中声明的形参个数一致
