
1.面向对象的三大特性
    封装
        成员的私有化，只能在类中被访问，在类的外面，访问不了
        私有化方式
            命名单下划线开始: 只是一种约定，不具备强制性
            命名双下划线开始,至多一个下划线结束 。  底层是通过改名的方式实现的私有化
            如果通过  _类名__成员名
        注意：
            属性私有化的目的，并不是让类的外部彻底不能获取或者修改属性的的值
            是想在修改或者获取属性的值的时候，加一些限制
            所以属性私有化之后，一般我们会提供公开的获取以及设置属性值的方法
            在python语言中，为了淡化私有的过程，可以通过@property + @私有属性去掉双下划线.setter 修改方法（方法名是私有属性去掉双下划线），
            那么这样在调用方法的时候，可以通过类似操作属性的方式去调用
                例如：  对象.名           ---获取值
                       对象.名 = 值      ---设置值
    继承
        子类(派生类)可以从父类(基类)中继承所有非私有成员
        单继承：
            class 子类(父类):
                pass
        多继承
            class 子类(父类1,父类2,父类3....)

        复用父类的方法
            父类名.方法名()
            super().方法名()
            注意：如果不存在重写，也可以通过self.方法名()去访问父类中的方法，但是这个时候，方法是从父类继承的
                 如果存在重写,self.方法名访问的是本类的方法
        方法的重写
            在子类中，可以定义和父类同名的方法，重新实现功能，这种形式叫做方法的重写。 在调用的时候，会执行子类中重写的方法

            在一个类中，如果定义多个同名的方法，后面定义的会将前面定义的覆盖掉，那么名字相同，参数不同
            也就是说，python中是没有重载的

        方法解析顺序
            可以通过类名.__mro__查看当前类方法的解析顺序
                顺序和定义子类的时候，父类的继承顺序是有关系的
                class 子类(父类1,父类2):
                当前类->继承的父类1->继承的父类2->父类的父类

    多态
        一个对象的多种不同形态
        方法的参数--体现多态
        方法的返回值--体现多态
